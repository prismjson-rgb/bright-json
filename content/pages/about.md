JSON Prism is a free, open-source JSON toolkit that runs entirely in your browser.

- **Format** — Pretty-print or minify JSON
- **Validate** — Check syntax and structure
- **Diff** — Compare two JSON documents
- **Explore** — Tree view, search, and navigation

No data is stored or sent to any server. Everything runs locally. Works offline.
