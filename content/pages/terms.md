## Description of service

JSON Prism is a free, browser-based tool that provides the following functionality:

- JSON formatting, minification, and validation
- Collapsible tree view, visual (form-based) editor, and flow/graph view
- JSON diff (comparison) viewer
- JSON conversion to YAML, XML, and CSV
- In-browser search across keys and values
- JSON debugger with auto-fix suggestions
- JSON trimmer (strict-mode cleanup)
- AI response cleaner (extracting JSON from LLM output)
- Minimal mode for path-based payload reduction
- Structure analyzer, best-practices checker, and token estimator
- Mock JSON data generator
- Rich-text notes (stored locally on your device)
- Import from file, URL, or drag-and-drop
- Share via URL fragment or optional 30-day short link

All processing occurs locally in your browser. JSON content is never sent to any server except when you explicitly opt in to short links — see the Privacy Policy for details.
