## What is JSON Prism?

JSON Prism is a free, browser-based JSON toolkit built for developers. It combines 19 JSON tools in a single workspace - format, validate, diff, convert, debug, edit, and analyze JSON without installing anything or sending data to a server.

## Core tools

**JSON Formatter** - Beautify minified payloads into readable, indented output in one step. Works on any valid JSON instantly.

**JSON Validator** - Check JSON syntax with inline error highlighting. Pinpoints missing commas, unquoted keys, trailing commas, and other common mistakes.

**JSON Diff Viewer** - Compare two JSON documents side-by-side. Highlights added keys (green), removed keys (red), and changed values. Structural comparison, not line-by-line, so formatting differences are ignored.

**JSON Converter** - Convert between JSON, CSV, XML, and YAML. Useful when working with APIs that return one format but your pipeline expects another.

**JSON Debugger** - Goes beyond validation to explain errors in plain language and suggest fixes. Detects invisible characters, truncated LLM output, and non-standard JSON variants.

**JSON Tree View** - Navigate deeply nested JSON with a collapsible tree. Select any node to see its JSONPath expression. Search by key or value.

**AI JSON Cleaner** - Extracts valid JSON from LLM output that is wrapped in prose, markdown code fences, or partial formatting.

**JSON Token Estimator** - Count tokens in your JSON for OpenAI, Anthropic, and other LLM APIs. Shows token counts for both pretty-printed and minified versions.

## Why use JSON Prism?

Every tool opens from the left sidebar and shares the same JSON editor - you do not need to copy and paste between separate browser tabs. Format, then validate, then diff, then edit, then share, all in one place. The workspace also supports deep links: tool landing pages link directly into the right mode so you land in the exact feature for your search query.
